## 📖 Descripción General

**Mi Gusto MES** es una plataforma web de alto rendimiento diseñada para digitalizar, centralizar y optimizar las operaciones de producción industrial. Este sistema actúa como el núcleo neurálgico entre la planificación operativa y la ejecución en planta, brindando visibilidad instantánea sobre el estado de la línea de producción, rendimiento térmico y trazabilidad de lotes.

Desarrollado de manera integral por el **Departamento de Sistemas de Mi Gusto**, el sistema elimina los procesos manuales y centraliza el control de tiempos, salidas por sector y métricas clave de calidad.

---

## ✨ Módulos y Funcionalidades Principales

- 📊 **Dashboard de Control y Analítica**: Visualización en tiempo real de indicadores clave de rendimiento (KPIs), cumplimiento de metas diarias, rendimiento térmico y gráficos estadísticos interactivos.
- 📅 **Programación de Producción**: Interfaz ágil para la planificación, asignación y agendamiento diario de órdenes de trabajo por sector y línea productiva.
- 📦 **Producción en Tiempo Real**: Panel operativo intuitivo para el registro continuo de avances, control de salidas por sector y seguimiento del estado de lotes activos.
- 📜 **Historial y Trazabilidad**: Repositorio histórico para auditorías operativas, consulta de lotes finalizados y análisis de tendencias de producción.
- 🖥️ **Interfaz de Planta (Screen Mode)**: Vista de alto contraste tipo HUD (Heads-Up Display) optimizada para monitores industriales de planta, garantizando máxima legibilidad a distancia.

## 🛠️ Tecnologías Principales

- **Frontend Core**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Estilos & UI**: [Tailwind CSS](https://tailwindcss.com/) + [Lucide Icons](https://lucide.dev/)
- **Visualización de Datos**: [Recharts](https://recharts.org/)
- **Backend & Autenticación**: [Supabase](https://supabase.com/)

## 🔒 Seguridad y Control de Acceso

El acceso a la plataforma está regulado mediante la autenticación de **Supabase**, incorporando políticas de acceso por roles (*Role-Based Access Control*) que aseguran que únicamente el personal autorizado de cada sector pueda modificar o consultar datos críticos del proceso productivo.
